# Roles

Core roles are architecture lead, sole FPGA writer, verification engineer, CDC/timing reviewer, interface architect, vendor-platform reviewer, board-validation engineer, and independent FPGA final reviewer. Conditional roles are cross-domain system architect, sequential firmware writer, datasheet specialist, and cross-domain release reviewer.

Nine roles explicitly use a read-only sandbox. The default write order is product FPGA sources, optional firmware, then optional verification assets. Reviewers report findings and never fix them. Implementers cannot sign their own work.
